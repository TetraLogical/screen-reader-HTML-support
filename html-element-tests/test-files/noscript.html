<noscript> element

JavaScript is enabled. Fallback content inside <noscript> should not be rendered.

Pass Criteria

  • #1: Element is parsed and present in the DOM
  • #2: When JavaScript is enabled, content inside <noscript> is not rendered
  • #3: When JavaScript is disabled, the fallback content is rendered and operable

  • MDN Web Docs: <noscript>
